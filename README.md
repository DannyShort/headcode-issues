# Headcode issues

The place to report problems with [Headcode](https://headcode.io) and suggest ideas for it.

- **[Report a problem](https://github.com/DannyShort/headcode-issues/issues/new?template=bug_report.yml)**
- **[Suggest an idea](https://github.com/DannyShort/headcode-issues/issues/new?template=feature_request.yml)**

You can also get to both from the app, under **Settings → Feedback**, which fills in your app version and device for
you. You'll need a free GitHub account. If you'd rather not, or it's about your account or data, email
[hello@headcode.io](mailto:hello@headcode.io).

Before opening a new one, please search the [open issues](https://github.com/DannyShort/headcode-issues/issues) and
add a 👍 to any that match: it's how we tell what matters most.

## What the labels mean

| Label | |
|---|---|
| `triage` | New, not looked at yet |
| `needs info` | We need more detail from you to look into it |
| `planned` | We're going to do it |
| `in progress` | Being worked on |
| `released` | Fixed or added; reload the app (or tap **Get** under Settings → About) to get it |
| `duplicate`, `won't do` | Closed for that reason |

When a change to Headcode fixes an issue here, the issue is closed automatically and links to the change.
